# The Deep

A 2.5D side-scrolling metroidvania, made with Godot .NET (C#), about an android pilgrim descending toward a planet's core. The game is built by a coding agent; the owner plays it and gives feedback.

- **Play:** `godot --path .` (Godot .NET and the .NET SDK, `instructions/toolchain.md`). Other ways in, and what to try: `instructions/testing.md#playtest`.
- **What the game is:** [docs/vision.md](docs/vision.md).
- **Where it stands, and the plan:** [docs/roadmap.md](docs/roadmap.md).
- **How the work is done:** [AGENTS.md](AGENTS.md), the instructions every agent session follows, with its parts in [instructions/](instructions/); the shared understanding of the project is in [docs/](docs/).
