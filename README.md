# The Deep

A 2.5D side-scrolling metroidvania, made with Godot .NET (C#), about an android pilgrim descending toward a planet's core. The game is built by a coding agent; the owner plays it and gives feedback.

- **Play:** `godot --path .` (Godot .NET and the .NET SDK, `docs/toolchain.md`). Other ways in, and what to try: `docs/testing.md#playtest`.
- **What the game is:** [docs/vision.md](docs/vision.md).
- **Where it stands:** [docs/state.md](docs/state.md); the plan: [docs/roadmap.md](docs/roadmap.md).
- **How the work is done:** [AGENTS.md](AGENTS.md), the instructions every agent session follows, and the docs it points to in [docs/](docs/).
